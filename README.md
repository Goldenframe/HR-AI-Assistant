# HR AI Assistant

Telegram-бот для сбора обратной связи о сотрудниках. Предлагает коллег по совместным проектам в Jira и Confluence, отправляет приглашения и собирает ответы по корпоративной анкете. Корпоративная ИИ Qwen готовит краткий отчёт с сильными сторонами, зонами развития и рекомендациями. Исходные ответы можно скачать в Excel.

Каталог действующих сотрудников загружается из TRCK. Jira и Confluence используются для подбора коллег, а не как справочник сотрудников.

## Как пользоваться сотруднику

Устанавливать Python или Teleport сотруднику не нужно: бот должен быть запущен организатором.

### Подключить профиль

1. Откройте Telegram-бота, ссылку на которого выдал организатор, и нажмите **Старт**.
2. Отправьте свой одноразовый код подключения, полученный у организатора.
3. После подключения появится главное меню. При следующих обращениях код не нужен.

Код связывает Telegram-аккаунт с рабочим профилем. Код HR выдаётся отдельно и открывает доступ к отчётам обо всех сотрудниках.

### Запросить обратную связь

1. Нажмите **Получить обратную связь** и дождитесь подбора коллег.
2. Проверьте список. Можно убрать людей, выбрать всех, снять все отметки или добавить сотрудника из каталога через поиск. Общий проект для ручного добавления не обязателен.
3. Выберите минимум трёх коллег и нажмите **Запустить опрос**.
4. Бот сам отправит приглашения. Коллегам, которые ещё не подключили профиль, приглашения придут после подключения. Пересылать их вручную не нужно.
5. Откройте **Мои отчёты**, выберите опрос и посмотрите статистику. После минимум трёх завершённых отзывов станут доступны **Получить отчёт** и **Ответы коллег — Excel**.

Участие в одном проекте не всегда означает непосредственную совместную работу, поэтому список нужно проверить до запуска. После запуска список получателей фиксируется.

### Оставить отзыв

1. В приглашении нажмите **Оставить отзыв** и прочитайте условия использования ответов.
2. Выберите **Согласен, начать**, **Не участвовать** или **Напомнить позже**.
3. Заполните анкету: 43 утверждения со шкалой согласия и 7 комментариев. Для утверждений можно выбрать **Затрудняюсь ответить**, для комментария — **Пропустить комментарий**.
4. В конце при необходимости откройте **Просмотреть мои ответы** и исправьте нужные ответы.
5. Нажмите **Отправить отзыв**. Только после этого он учитывается при подготовке отчёта.

Незавершённые ответы сохраняются. **Отменить ответ** удаляет незавершённый отзыв. Напоминание можно назначить через 5 минут, час, 3 часа, день, два дня или неделю. Это напоминание по выбранному получателем сроку, а не регулярная рассылка всем неответившим. Оно приходит, пока бот работает; если бот был выключен, просроченное напоминание отправится после запуска.

### Получить результат

Отчёт содержит краткие наблюдения, варианты развития, расхождения во мнениях при их наличии и сопоставление тем с корпоративными ценностями. Рекомендации не являются обязательными задачами со сроком исполнения.

При доступном подключении бот получает из Jira сведения о незавершённых задачах сотрудника и использует их как контекст рекомендаций. Эти сведения не показывают полную загрузку и не используются для оценки эффективности. Недоступность данных о задачах не блокирует отчёт.

**Ответы коллег — Excel** выдаёт один XLSX: вопросы расположены по столбцам, отзывы — по строкам. Авторы обозначены номерами. Выгрузка доступна после трёх завершённых отзывов, даже если ИИ временно недоступна.

HR через **Панель HR** может запускать опросы о сотрудниках, отслеживать сбор и открывать результаты. Обычный сотрудник видит только отчёты о себе.

## Запуск организатором

### Что понадобится

- Python 3.10 или новее. Сторонние pip-пакеты не требуются.
- Токен Telegram-бота от BotFather. Для проверки используйте отдельного бота: две копии с одним токеном одновременно запускать нельзя.
- Доступ к корпоративной ИИ через Teleport. Для корпоративного режима также нужны доступ к TRCK и токены Jira/Confluence Server/Data Center.
- На Windows — Teleport Connect либо CLI `tsh`; на macOS/Linux для скриптов туннелей — Bash и `tsh`.

### Скачать проект и создать настройки

Скачайте ветку `feat/add-tg-bot` через GitHub (**Code → Download ZIP**, затем распакуйте) или клонируйте репозиторий:

```bash
git clone --branch feat/add-tg-bot https://github.com/Goldenframe/HR-AI-Assistant.git
cd HR-AI-Assistant
```

Все команды ниже выполняются из папки проекта. Скопируйте `.env.example` в `.env`:

| Windows, PowerShell | macOS/Linux |
| --- | --- |
| `Copy-Item .env.example .env` | `cp .env.example .env` |

Если `.env` уже существует, отредактируйте его, не заменяя образцом. Заполните `TELEGRAM_BOT_TOKEN`, `AI_BASE_URL`, `AI_API_KEY` и `AI_MODEL`. Не добавляйте `.env` в Git и не пересылайте его коллегам.

Без `TELEGRAM_BOT_TOKEN` бот предложит скрытый ввод в терминале и сохранит токен после успешной проверки. Адрес и ключ ИИ также могут читаться из провайдера `rc-ai` в конфиге Hermes; держать Hermes открытым не нужно. Явные настройки окружения имеют приоритет.

### Быстро проверить на вымышленной команде

Демо не требует импорта сотрудников из TRCK и участия реальных коллег. Доступ к корпоративной ИИ нужен для формирования отчёта.

**Windows**

1. В Teleport Connect откройте подключение к приложению `ai`.
2. Сверьте адрес с `AI_BASE_URL` в `.env`, например `http://127.0.0.1:62432/v1`. Если порт другой, исправьте настройку.
3. В PowerShell запустите:

```powershell
.\start.bat --demo-team
```

`start.bat` запускает Python-бота; вход в Teleport и туннели на Windows нужно подготовить отдельно.

**macOS/Linux**

Заполните `TSH_PROXY`, `TSH_USER` и `TSH_AUTH` в `.env`, затем выполните:

```bash
./scripts/demo.sh
```

Скрипт проверяет сессию `tsh`, при необходимости предлагает корпоративный вход, поднимает туннели, проверяет настройки и запускает демонстрационную команду. Если туннели уже подготовлены, можно использовать `./start.sh --demo-team`.

**Что должно произойти**

В терминале появятся имена вымышленных профилей и одноразовые коды. Откройте бота, отправьте `/start` и код одного из профилей. В меню появится **Демо**: эта кнопка создаёт отдельный опрос с тремя готовыми вымышленными отзывами. Откройте его отчёт и выгрузку Excel.

Для демонстрации трём участникам можно выдать профили **Анна Смирнова**, **Мария Иванова** и **HR демонстрационной команды**. Обычный опрос всё равно требует три отзыва от разных коллег; для показа готового анализа используйте отдельную кнопку **Демо**. Ответы демонстрационного опроса заранее подготовлены, их нельзя выдавать за завершённый живой цикл.

### Подключить корпоративную команду

1. Поднимите соединения Teleport для `ai`, `jira` и `confluence`. На macOS/Linux можно выполнить `./scripts/tunnels.sh up`; на Windows — открыть подключения в Teleport Connect. Порты из образца: AI — `62432`, Jira — `62452`, Confluence — `62451`. Сверьте их с URL в `.env`.
2. Заполните `.env`:

```dotenv
TEAM_SOURCE=atlassian
TEAM_DIRECTORY=data/corporate-team.json
DIRECTORY_SOURCE=trck
TRCK_API_URL=https://trck.rdclr.ru
JIRA_URL=http://127.0.0.1:62452
JIRA_PERSONAL_TOKEN=ваш_токен
CONFLUENCE_URL=http://127.0.0.1:62451
CONFLUENCE_PERSONAL_TOKEN=ваш_токен
```

3. Выполните `python tracker-login.py` на Windows или `python3 tracker-login.py` на macOS/Linux. В открывшемся браузере войдите в корпоративный аккаунт. Это отдельная сессия интеграции; входа в обычную вкладку TRCK недостаточно.
4. Импортируйте каталог и проверьте участие в проектах:

| Действие | Windows, PowerShell | macOS/Linux |
| --- | --- | --- |
| Импорт сотрудников | `.\start.bat --import-team` | `./start.sh --import-team` |
| Проверка проектов | `.\start.bat --check-team` | `./start.sh --check-team` |
| Запуск бота | `.\start.bat` | `./start.sh` |

Импорт не отправляет приглашений. Действующие сотрудники берутся из TRCK, соответствие аккаунтам Jira проверяется по точной уникальной почте. Неподтверждённые аккаунты не подставляются по похожему имени. Проверьте связи проектов Jira и пространств Confluence в `data/corporate-team.json`; неподтверждённые связи не означают отсутствия сотрудника в команде. Подробности — в [инструкции по каталогу](docs/tracker-directory.md).

После запуска выдайте сотрудникам их коды из терминала, а уполномоченному HR — код HR. Уже подключённые профили и ответы сохраняются после перезапуска. Коды неподключённых профилей перевыпускаются при каждом запуске.

Держите бот и соединения Teleport работающими. Для остановки бота нажмите **Ctrl+C**. Туннели macOS/Linux: `./scripts/tunnels.sh status` и `./scripts/tunnels.sh down`.

## Частые вопросы

| Проблема | Что проверить |
| --- | --- |
| Коллеге не пришло приглашение | Он должен один раз нажать «Старт» и подключить профиль. Проверьте статус доставки в карточке опроса и не заблокирован ли бот. |
| Кнопки отчёта ещё нет | Нужно минимум три завершённых и отправленных отзыва. Черновики не учитываются. |
| ИИ недоступна или вернула ошибку | Проверьте соединение `ai` в Teleport, `AI_BASE_URL`, ключ и доступность корпоративного сервиса. Исходные ответы сохраняются; отчёт можно запросить повторно. |
| Не найден нужный сотрудник | Обновите каталог TRCK через `--import-team`. В существующем каталоге используйте «Добавить коллегу» и поиск. |
| TRCK требует повторный вход | Снова выполните `tracker-login.py`, затем импорт. |
| Не работает код подключения | Используйте код последнего запуска. Уже использованный код не подходит для подключения другого аккаунта. |
| Бот перестал отвечать | Проверьте окно запуска, интернет и отсутствие второй копии с тем же токеном. В сети с обязательным системным прокси настройте `TELEGRAM_USE_PROXY=1`. |

## Данные и ограничения

- Корпоративные данные хранятся в `data/corporate.sqlite3`, демонстрационные — в `data/feedback.sqlite3`. Привязки и ответы между режимами не смешиваются.
- Telegram не позволяет боту первым начать личный диалог: каждый коллега должен сам открыть бота и подключить профиль.
- Исходные ответы доступны сотруднику, о котором собрана обратная связь, HR и администратору хранилища. В Excel нет полей с авторами, но текст комментариев не очищается от написанных в нём имён. Порог трёх отзывов не гарантирует анонимность.
- ИИ получает ответы для анализа. Программа проверяет ссылки на исходные цитаты, но такая проверка не гарантирует смысловую правильность всех выводов. Сопоставление с ценностями выполняется по разделам анкеты и не является формальной оценкой сотрудника.
- Общий проект — косвенный признак взаимодействия. Подбор зависит от доступных данных и прав Jira/Confluence, не проверяет совпадение периодов работы и требует просмотра списка инициатором.
- Бот автоматизирует обработку, но не гарантирует срок ответа коллег. Напоминания и доставка работают только при запущенном боте.
- Для демонстраций используйте вымышленные отзывы. Токены, база и локальные результаты не должны попадать в репозиторий.

## Проверки и техническая документация

Локальные программные тесты не отправляют настоящие приглашения:

```bash
python -m unittest discover -s tests -v
```

На macOS/Linux используйте `python3`. Проверка ИИ на синтетических ответах: `start.bat --check-ai` / `./start.sh --check-ai`. Расширенный прогон: `--evaluate-ai`; результаты сохраняются локально в `data/evaluation.json`. Проверки отдельных свойств не заменяют содержательную оценку отчёта человеком.
