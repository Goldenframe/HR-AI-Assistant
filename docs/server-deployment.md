# Круглосуточный тестовый бот

Подготовлена конфигурация для Linux-сервера с Docker Engine и Docker Compose 2.30 или новее. Сервер ещё не выбран, приложение не развёрнуто. Настройка рассчитана на вымышленные профили и отзывы. Корпоративный каталог, SQLite и локальные ключи не попадают в Docker-образ.

## Что требуется от DevOps

- Linux-сервер с исходящим доступом к Telegram API и корпоративной ИИ. Входящий HTTP-порт для бота не нужен: используется polling.
- Запуск Docker Engine при загрузке сервера.
- Постоянный машинный доступ к приложению `ai` через Teleport, либо другой согласованный адрес корпоративной ИИ, доступный с сервера. Teleport Connect на ноутбуке не обеспечивает такую связь.
- Передача текущих секретов непосредственно в локальный файл `.env.server` на сервере. Они не включаются в Git и образ.

## Постоянное соединение Teleport

Администратор Teleport создаёт Machine Identity для проекта и даёт доступ к приложению AI. `tbot` запускается как постоянная служба сервера и открывает `application-tunnel` на `tcp://127.0.0.1:62432` для `app_name: ai`. В контейнере используется сеть Linux-хоста, поэтому `AI_BASE_URL=http://127.0.0.1:62432/v1` обращается к этому серверному туннелю.

Регистрацию машинной идентичности и способ join выбирает администратор корпоративного Teleport. Их нельзя заменить копированием сеанса Teleport Connect с ноутбука. Не требуется переносить на сервер интерактивный вход пользователя.

Документация: [Teleport application-tunnel](https://goteleport.com/docs/reference/machine-workload-identity/configuration/#application-tunnel), [Machine Identity application access](https://goteleport.com/docs/machine-workload-identity/machine-id/access-guides/applications/).

Для текущего теста доступны только вымышленные проекты из fixtures. Jira/Confluence не используются при запуске этой конфигурации. В будущем для реального режима потребуются отдельная настройка и разрешение на реальные приглашения.

## Первый запуск — один раз

Перед запуском остановите локальную копию с тем же Telegram-токеном. Одновременно должен работать только один polling-процесс для одного бота.

На сервере в каталоге репозитория:

```sh
cp .env.server.example .env.server
chmod 600 .env.server
# Заполнить TELEGRAM_BOT_TOKEN, AI_BASE_URL и AI_API_KEY локально на сервере.
docker compose build
docker compose run --rm feedback-bot python -c "from server import validate_environment; import os; validate_environment(os.environ); print('Settings OK')"
docker compose up -d
docker compose logs --tail=100 feedback-bot
```

В первом журнале появятся одноразовые коды вымышленных профилей. Организатор подключает профили участников теста один раз. SQLite хранится в постоянном томе `demo-data`. Обычный перезапуск и `docker compose down` без `-v` сохраняют профили и отзывы. Не копируйте корпоративную базу в тестовый том.

Секреты нельзя публиковать вместе с журналом: журнал содержит коды подключения профилей. Бот не печатает значения API-ключей. Команда `docker compose config` может раскрыть значения env_file, поэтому её вывод не следует передавать в чат.

После запуска контейнер работает в фоне и перезапускается после завершения процесса. При автоматическом запуске Docker после перезагрузки сервера возобновится и бот. При временной сетевой ошибке текущий polling повторяет подключение. Если туннель AI недоступен, бот сохраняет сбор ответов, но выдача отчёта требует восстановления туннеля.

Правило `unless-stopped` не включает вручную остановленный контейнер. Для возвращения после `docker compose stop` выполните `docker compose up -d`. Политика описана в [Docker Compose restart](https://docs.docker.com/reference/compose-file/services/#restart).

## Обновление и остановка

```sh
docker compose up -d --build
docker compose logs --tail=100 feedback-bot
docker compose stop
```

Обновление исходников выполняет ответственный за сервер; бот не скачивает и не запускает новый код сам. Резервное копирование тома и мониторинг доступности сервера настраиваются при развёртывании. Круглосуточная работа зависит от доступности сервера, Telegram и корпоративного доступа.
