# Каталог сотрудников из TRCK

Источник: GET /api/v1/users с isActive=true и userType=EMPLOYEE, с проверкой всех страниц. Jira и Confluence используются только для определения совместных проектов.

1. Выполните `python tracker-login.py` и войдите через корпоративную страницу в браузере. Пароль бот не хранит. Токены сохраняются в игнорируемой папке data и автоматически обновляются, пока корпоративная сессия допускает обновление.
2. Задайте DIRECTORY_SOURCE=trck и TRCK_API_URL=https://trck.rdclr.ru в .env.
3. Выполните `./start.sh --import-team` (или `python bot.py --import-team`), затем перезапустите бот.

Сопоставление Jira выполняется по точной уникальной почте. Неподтвержденные аккаунты не подставляются по имени. Сотрудники без соответствия в Jira доступны для ручного добавления. Роли HR назначаются отдельно и не выводятся из имени или роли трекера. Существующие идентификаторы Jira сохраняются вместе с привязкой Telegram. При обновлении исключенные профили скрываются, их коды аннулируются, а из черновиков убираются их приглашения. Завершенные ответы сохраняются.

Импорт при неполных страницах или сбое не заменяет каталог. При истечении сессии выполните вход повторно. Браузерный вход в сайт и вход локальной интеграции — разные сессии.
